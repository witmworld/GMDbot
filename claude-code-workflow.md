# 🤖 Инструкция: Как давать задания Claude Code из claude.ai

## Контекст
**Claude Code** — это отдельный инструмент (командная строка) для работы с кодом на твоём компьютере.  
**claude.ai** (этот чат) — это веб-интерфейс, где ты общаешься с Claude.

Они **НЕ связаны** напрямую, но ты можешь использовать claude.ai для **написания заданий** для Claude Code.

---

## Как это работает

### Шаг 1: Создай задание в claude.ai
В этом чате (claude.ai) попроси меня (Claude):

> "Создай задание для Claude Code: [описание задачи]"

Я создам **детальное техническое задание** в формате Markdown (.md файла).

### Шаг 2: Скачай файл с заданием
Я предоставлю файл для скачивания. Сохрани его на компьютер.

### Шаг 3: Открой Claude Code
В терминале:
```bash
claude-code
```

### Шаг 4: Загрузи задание в Claude Code
В Claude Code напиши:
```
@filename.md

[Любой дополнительный контекст если нужен]
```

Или просто скопируй текст задания и вставь в Claude Code.

### Шаг 5: Claude Code выполнит задание
Claude Code:
- Прочитает задание
- Найдёт нужные файлы в проекте
- Внесёт изменения
- Сделает git commit
- Может сделать git push (если попросишь)

## Пример: Сканирование админов группы

### В claude.ai (этом чате):
```
Создай задание для Claude Code: нужно запустить сканер админов 
в Telegram группе GMD Club. Команда /scan_group уже существует, 
нужно проверить что она работает и запустить.
```

### Я создам файл `scan-group-task.md` с детальным заданием

### В Claude Code (терминал):
```bash
cd ~/gmd-bot
claude-code
```

Затем в Claude Code:
```
@scan-group-task.md

Проверь команду /scan_group и запусти сканирование админов группы.
```

Claude Code сделает всё автоматически!

## Важные правила

### ✅ Делай так:
1. **Всегда указывай полный контекст** в задании:
   - Название проекта
   - Путь к файлам
   - Что уже сделано
   - Что нужно сделать

2. **Используй skill** если есть:
   ```
   Следуй skill 'telegraf-bot-structure' при изменении index.js
   ```

3. **Проси показать код** перед изменениями:
   ```
   Сначала покажи текущий код команды /scan_group, 
   затем предложи изменения
   ```

4. **Проверяй результат**:
   ```
   После изменений покажи git diff
   ```

### ❌ Не делай так:
1. Не давай расплывчатые задания:
   - ❌ "Исправь бота"
   - ✅ "Добавь защиту от дублей в scenes/admin-receipts.scene.js"

2. Не забывай про env переменные:
   - Если задание требует API ключи, укажи где их взять

3. Не пропускай тестирование:
   - Всегда проси Claude Code показать как протестировать изменения


## Частые вопросы

**Q: Могу ли я общаться с Claude Code напрямую из claude.ai?**  
A: Нет, они не связаны. claude.ai помогает **написать задание**, а Claude Code **выполняет** его на твоём компьютере.

**Q: Нужно ли каждый раз создавать файл с заданием?**  
A: Нет, для простых задач можешь просто скопировать текст из claude.ai и вставить в Claude Code.

**Q: Как передать файлы между claude.ai и Claude Code?**  
A: Через скачивание/загрузку или копирование текста. Они работают независимо.

**Q: Что если Claude Code не понимает задание?**  
A: Вернись в claude.ai, попроси меня уточнить или расширить задание.

## Workflow для больших проектов

### 1. Планирование (claude.ai)
```
Проанализируй проект GMD Bot и предложи как добавить функцию X
```
Я дам тебе план и список файлов которые нужно изменить.

### 2. Создание заданий (claude.ai)
```
Создай 3 отдельных задания для Claude Code:
1. Создание новой сцены
2. Добавление кнопки в меню
3. Тестирование
```

### 3. Выполнение (Claude Code)
Загружай задания по одному в Claude Code и выполняй.

### 4. Проверка (claude.ai + Claude Code)
Если что-то не работает — скопируй ошибку из Claude Code, вставь в claude.ai, я помогу исправить.

## Пример полного цикла

**День 1: Планирование**
- claude.ai: "Как добавить экспорт данных в Excel?"
- Claude даёт план и создаёт 3 задания

**День 2: Разработка**
- Claude Code: выполняет задание 1 (создание сцены)
- Claude Code: выполняет задание 2 (добавление кнопки)
- Git push → Railway автодеплой

**День 3: Тестирование**
- Telegram: тестируешь функцию
- Находишь баг
- claude.ai: "В экспорте ошибка [текст ошибки]"
- Claude создаёт задание на фикс
- Claude Code: исправляет

**День 4: Документация**
- claude.ai: "Обнови GMDClub-Progress.md с новой функцией"
- Claude создаёт обновлённый документ
